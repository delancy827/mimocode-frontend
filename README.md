# MiMoCode Frontend

A Codex-style desktop frontend for MiMoCode built with Electron + React + TypeScript + Tailwind CSS.

## Features

- Two-column layout with sidebar and chat area
- Task management with search and filtering
- File browser with tree view
- Memory search panel
- Terminal integration
- Command palette with keyboard navigation
- Dark theme with modern design

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- Electron
- React 18
- TypeScript
- Zustand (state management)
- Tailwind CSS
- Vite
- Monaco Editor
